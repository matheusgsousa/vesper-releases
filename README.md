# Vesper — releases

Executáveis oficiais do **Vesper para Windows**. Este repositório guarda só as
versões publicadas; o código-fonte é privado.

- **Download:** [Releases mais recente](https://github.com/matheusgsousa/vesper-releases/releases/latest) → `Vesper-windows-x64.exe`
- **Site:** https://vesperbypass.tech/download
- **Integridade:** cada release traz o SHA-256 do executável (`Vesper-windows-x64.exe.sha256`
  e o digest exibido pelo GitHub). O app só instala atualizações cujo SHA-256 confere.

## Requisitos

Windows 10 22H2 ou Windows 11, 64 bits, com .NET Framework 4.8 e Microsoft Edge
WebView2 Runtime (já presentes no Windows atualizado). Não pede permissão de
administrador.

## Prévia

Nesta prévia, conta e assinatura (Mercado Pago) são reais; a rota de rede do
Discord e as regiões ainda são **simuladas** e assim identificadas no app. O
executável ainda não tem assinatura digital: se o SmartScreen aparecer, clique
em "Mais informações" → "Executar assim mesmo" depois de conferir o SHA-256.

O Vesper é software proprietário e independente, sem afiliação oficial com o
Discord. Avisos de terceiros: `Vesper-NOTICES.txt` em cada release.
