## Novidades da 0.4.2 — Janela moderna integrada e tamanho fixo

Publicada em 30/10/2026.

**Visual limpo sem barras duplicadas do Windows e controles nativos integrados diretamente no app.**

### Novidades
- **Janela moderna integrada.** Os botões nativos do Windows foram substituídos por controles elegantes de Fechar e Minimizar integrados diretamente no topo do app, mantendo o arraste natural da janela.
- **Tamanho fixo consistente.** O tamanho da janela agora é fixo em 1180×800, impedindo redimensionamentos acidentais e garantindo o layout perfeito em todas as telas.

## Requisitos

- Windows 10 ou Windows 11, 64 bits.
- Na primeira conexão, o Windows pede sua permissão para preparar a rota do Discord.
- Se o Windows avisar ao abrir o arquivo, clique em "Mais informações" e depois em "Executar assim mesmo".

## Integridade

Cada release traz o SHA-256 do executável (`Vesper-windows-x64.exe.sha256` e o digest exibido pelo GitHub). O app só instala atualizações cujo SHA-256 confere.

O Vesper é software proprietário e independente, sem afiliação oficial com o Discord. Avisos de terceiros: `Vesper-NOTICES.txt` em cada release.
